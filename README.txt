مرکز آموزشی نگین - نسخه جامع
فایل اصلی: index.html
فایل پایگاه داده: supabase.sql
راهنما:
1) supabase.sql را در Supabase SQL Editor اجرا کنید.
2) در Authentication یک حساب مدیر بسازید.
3) UUID مدیر را در public.admin_users وارد کنید.
4) در index.html مقدار YOUR_SUPABASE_URL و YOUR_SUPABASE_ANON_KEY را با Project URL و Publishable/Anon Key عوض کنید.
هرگز Service Role/Secret Key را داخل سایت قرار ندهید.
