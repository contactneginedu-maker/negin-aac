# 💎 نگین AAC (Negin AAC)

**سامانه ارتباط جایگزین و افزوده برای کودکان**  
هر کودک، یک صدا؛ هر صدا، یک نگین

نسخه **۱.۲** با پشتیبانی کامل دو زبانه **دری + پشتو**

## ویژگی‌های کلیدی

- ✅ پشتیبانی کامل دو زبانه دری و پشتو (با یک دکمه تعویض زبان)
- ✅ بیش از ۵۰ نماد ارتباطی با ترجمه دقیق هر دو زبان
- ✅ رابط کاملاً راست‌چین (RTL)
- ✅ تبدیل متن به گفتار (TTS) با تشخیص زبان
- ✅ جستجو، دسته‌بندی، علاقه‌مندی‌ها و کلمات اخیر
- ✅ دکمه کمک فوری
- ✅ حالت آفلاین با Service Worker
- ✅ آماده ساخت APK اندروید

## نحوه تعویض زبان

دکمه **پښتو** / **دری** در بالای صفحه قرار دارد.  
زبان انتخاب‌شده ذخیره می‌شود و در بازدید بعدی حفظ می‌گردد.

